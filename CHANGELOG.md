# Changelog

## 0.1.0 — 2026-05-28

Initial release.

- `poppai.sh` — terminal flower statusline with 11 moods, 16 achievements, four interactions (pet / feed / dance / status), animated ASCII art, rainbow gradient bars
- `statusline-compact.sh` — single-line variant (model / context / cost / GPU bar / top process)
- `statusline.sh` — multi-line variant that staples Claude session info onto a full nvitop dashboard
- `install.sh` — picks a variant, copies it to `~/.claude/poppai.sh`, wires it into `settings.json`
- Three docs: `README.md`, `CUSTOMIZATION.md`, `CONTRIBUTING.md`
- MIT licensed
